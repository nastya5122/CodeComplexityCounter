## Описание проекта
Программа представляет собой настольное Java-приложение (Swing GUI) для автоматического расчета временной сложности исходного кода по методу Big O ($O(1)$, $O(N)$, $O(N^2)$ и т.д.).

## Архитектура и алгоритм
Программа работает по принципу посимвольного и построчного парсинга текста:
1. **Вход:** Пользователь вставляет исходный код в текстовое поле приложения.
2. **Обработка (Стек):** Алгоритм ищет ключевые слова циклов (`for`, `while`). Для точного определения глубины вложенности используется структура данных **Стек (Stack)** на базе `ArrayList`. При нахождении скобки `{` глубина увеличивается, при `}` — уменьшается.
3. **Выход:** На основе максимальной зафиксированной глубины стека программа рассчитывает финальную сложность алгоритма и выводит её в диалоговом окне.
